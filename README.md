# pl-mpr-client

This repository builds the following ROM:

*	Rom-client.JPN.srl `sha1: ff6ef65840c88e9af4cfd52933945a83ffd4d02b`
	
	(without signature: `sha1: ff5f42b4668d8bb6093b24d78ebeaa60cd85d840`)

To obtain this ROM, unpack a dump of "Minna no Pokemon Bokujou - Platina Taiouban (Japan)" using [ShowMiiWads](https://github.com/WiiDatabase/showmiiwads-mod/) or similar, and then extract it from `00000006.app` by removing the size `60h` header from it.

For build instructions, see [`INSTALL.md`](/INSTALL.md).

This decompilation is heavily based upon [pokeplatinum](https://github.com/pret/pokeplatinum/), without which this would not be possible.
